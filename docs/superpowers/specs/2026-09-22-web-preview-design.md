# 宠物社网页预览版

用户已确认：沿用小程序浅绿风格，8 个页面可交互，AI 暂不接入，发布 GitHub Pages。

独立目录 `web-preview/`，独立 Git 仓库，不改变现有小程序或后端。发布内容仅为新网页、测试与说明，不包含原书 PDF、知识库、环境变量或真实用户数据。

使用原生 HTML/CSS/JavaScript，hash 路由兼容 GitHub Pages 的子目录与刷新。8 个页面：首页、宠物资料、症状选择、问诊、结果、疾病详情、治疗详情、历史记录。浅绿背景、深绿文字、白色卡片，手机优先、电脑双栏。

演示问诊仅收集观察信息并生成观察摘要，不执行临床分支、不生成疾病或用药建议。疾病与治疗详情使用明确的占位内容。AI 入口说明未接入。宠物资料、草稿和演示历史仅保存在当前浏览器；允许删除。浏览器禁用存储时使用内存并提示。显示 demo 状态贯穿全过程。

验证覆盖资料校验、问诊结果、历史重复保存、错误存储恢复；浏览器覆盖 8 个路由、手机宽度、刷新、完成问诊及查看历史。发布后验证公网网址和资源。
