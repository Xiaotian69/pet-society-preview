# 宠物社 · 网页体验版

沿用微信小程序的浅绿风格，提供手机和电脑都能打开的独立网页。

## 本版可以体验

- 日常首页、基础档案、快捷记录、照护事项、日常历史，以及原有宠物资料、症状选择、三轮观察、结果、疾病详情、治疗详情、问诊演示历史，共 12 页。
- 日常记录支持食欲、活动、排便和体重；照护事项由用户填写日期，可在首页或历史页标记完成。当前只支持同一只宠物的资料修正。
- 简化的演示档案（必填基本信息，选填照护信息）。真实后端的完整入诊表单未接入。
- 观察摘要、保存历史、重新打开、删除记录；数据仅存当前浏览器，最多 50 条历史。
- 浏览器存储不可用时，降级为当前页面会话保存并明确提示。
- 日常数据也只保存在当前浏览器，最多保留最近 500 条；照护事项只在打开网页时显示，不发送系统通知。

**AI 尚未接入。** 三个症状入口使用相同的观察记录流程，答案只生成观察摘要。疾病与治疗页为明确标记的占位布局，不显示诊断、处方或虚构的书籍证据。

## 本地预览

在本目录运行 `python -m http.server 5173 --bind 127.0.0.1`，打开 `http://127.0.0.1:5173/`。请使用 HTTP 服务访问，避免浏览器阻止本地文件的 ES module。

## 验证

```powershell
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

浏览器验证会启动仅监听本机的临时静态服务，检查手机和桌面布局、全部路由、存储、交互与刷新。截图写入已忽略的 `qa/`。

## GitHub Pages

Pages 配置：Deploy from a branch → `main` → `/ (root)`。静态资源均用相对路径，页面使用 hash 路由，支持仓库子目录及直接刷新。

## 后续接 AI

目前网页不发起模型或问诊 API 请求。未来接入时，将问诊操作放入独立 API 模块，调用部署在 HTTPS 服务器上的后端；复用原项目的 DeepSeek 适配和书籍证据校验，并恢复后端要求的完整入诊资料。模型密钥只存服务器环境变量，不写入静态网页或 GitHub 仓库。演示资料与真实问诊记录须使用不同存储命名空间。

这个仓库仅包含网页预览，未包含原始书籍、知识库、后端环境文件或真实宠物资料。
